    1. Paste the prompt into the AI chat.
    2. It first answers TOTAL SCENES: N — check N matches the scenes / images count shown above (about half your line count).

    Step 3 · Command

    Make the Flow prompt list

    One command turns original-scenes-prompts.txt into the Flow-ready prompt list — and verifies every scene sentence against your script, line by line.

    Run in the video's folder

    py pipeline.py prompts

    Open a terminal in the video's folder (in File Explorer: click the address bar, type cmd, press Enter) and paste the command.

    What you get

    1. flow-ai-scene-prompts.txt — one image prompt per scene, each numbered 001:, 002: … so you can search the file for one scene when you need to regenerate a single image.
    2. A verification result: "Verified: all N scene sentences match voice-over-script.txt" means you're safe.
    If it prints WARNINGS — the AI merged, skipped or reworded a line. Fix those scenes in original-scenes-prompts.txt (or ask the AI chat to redo them) and run the command again before generating any images.
    Step 4 · Reminder — your bulk extension

    Generate the images on Flow AI

    You already have this covered with your third-party bulk extension — this step is just the checklist so nothing is missed.

    1. Open Flow AI and load your character reference image (every prompt expects it).
    2. Feed your bulk extension the prompts from flow-ai-scene-prompts.txt — keep the order.
    3. Generate, then download all images into the Scene folder.
    Leave the downloaded names exactly as they are — 1.png, 1 (1).jpg, 2.webp are perfect. Step 7 renames them for you using that leading number.
    The one thing to do here: keep only one image per scene. If Flow gave you several variants of the same scene, delete the ones you don't want — otherwise the build flags them as duplicate scene numbers.
    Step 5 · Recording

    Record the voice-over

    Read voice-over-script.txt out loud — it's formatted as one breath per line, so pause naturally at each line break.

    1. Record at your natural pace — the timeline adapts to your timing automatically, so don't rush.
    2. Small stumbles are fine if you re-read the line cleanly; big retakes are better cut from the audio before the next step.
    Step 6 · Reminder — Cutback extension

    Create Transcript.srt

    You already do this with the Cutback extension — just the checklist:

    1. Run your recorded audio through Cutback to get the subtitles.
    2. Export/save as Transcript.srt in the video's folder.
    Short subtitle lines, ALL-CAPS, digits instead of words — all fine. The timeline builder normalizes everything ("8" matches "eight", etc.).
    Step 7 · Command

    Build the timeline

    One command renames your images, matches every one to the exact seconds it is spoken, adds the zoom/slide motion, the 5-frame dissolves and the sound effects, and writes timeline.xml.

    Run in the video's folder

    py pipeline.py build --scale 72
    This also renames the Flow downloads to 001 - sentence.jpg style first — you'll see a Rename: line at the top of the output. It's safe to re-run any time (already-correct names are left alone), so swap an image and rebuild whenever you like.

    Check the result

    1. Summary line: similarity 0.9+ is great.
    2. Any LOW CONFIDENCE flag = the only cut worth eyeballing in Premiere.
    3. Sound effects: line shows how many landed and on which tracks.
    You get two files: timeline.xml (the sequence) and apply-transitions.jsx (the Push / Zoom Blur accents, one every 5–8 cuts). Both are used in Step 8.

    Sound effects — automatic

    Anything in your SFX\ library is placed and mixed by this same command; there is nothing extra to run. A whoosh rides every Push/Zoom accent, an impact lands on the occasional ordinary cut, and a tick marks spoken numbers — arriving on their own tracks under your narration, already normalized so nothing is too loud.
    Whole thing too loud or too quiet? Rebuild with --sfx-gain -3 (or +3). None at all this time? --no-sfx. The library is shared across every video and set up once — see Step 8.
    Step 8 · Premiere Pro

    Import & finish

    Four moves. Everything arrives already assembled.

    1. Open YT Vid.prproj → File → Import → timeline.xml.
    2. Double-click the imported sequence to open it.
    3. Window → Extensions → Pipeline Transitions → click Apply transitions. It applies the accents, saves, and closes Premiere.
    4. Run py pipeline.py presets --open — swaps in your preset settings and reopens the project.
    Then drop your narration on A1 at 0:00 and play it through once. The sound effects come in on A2 and below, already mixed — A1 is left free for exactly this.
    🎉 That's the whole pipeline. Hit ☁ Save video one last time, then Start a new video in the sidebar when you begin the next one.

    One-time setup

    1. Install the panel — run once, then restart Premiere:
      py pipeline.py install-panel
    2. Save 6 transition presets in Premiere with the look you want, named exactly: Slide-Left Slide-Right Slide-Up Slide-Down Zoom-In Zoom-Out
    3. Build the sound library once — it lives at D:\YouTube\Mr Wise Max\YouTube Video Template\SFX\, which is now the default: nothing to pass, nothing to copy per video. Drop your Epidemic Sound downloads straight in — no sorting needed. Then check what landed where:
      py pipeline.py sfx
    Naming — easiest first. (1) Don't rename Epidemic files at all; their names already sort correctly. (2) For anything that won't sort, start the name with the category word — whoosh - deep long.wav, impact - heavy boom.wav, riser - 3s tension.wav, ui - soft click.wav, ambience - room tone.wav; everything after the category word is yours and is ignored. (3) Or drop the file straight into the matching subfolder — a folder always beats the name. Files sorted by name are marked [by name] in the report; anything it can't place is listed and left unused.
    Packed files split themselves. A .wav holding three whooshes in a row is detected at the silences and used as three separate effects — same file, different in/out points. A single sound with a quiet middle is never cut in half. Add --no-sfx-split to a build to switch it off.
    Looped or over-long files are trimmed with a fade. A 20-second ticking loop triggered by one spoken word would run across the narration, so anything longer than its category allows (whoosh 4s · impact 5s · riser 8s · ui 1.5s) is cut back and faded to silence over the last 0.4s rather than stopping dead. --sfx-fade 1.0 for a longer fade, --sfx-fade 0 for a hard cut, --sfx-max-len 0 to never trim.
    After a bulk import, stamp where they came from — py pipeline.py sfx --source "Epidemic Sound" — which fills credits.txt so provenance never goes missing. WAV over MP3: a WAV's loudness is measured and the level set from the audio itself; an MP3 can only be given a fixed quiet guess. Epidemic's WAV downloads are ideal.
    Connect your channel in the Epidemic dashboard before publishing — that's what whitelists it against Content ID claims on their own catalogue.
    Why the extra step? Premiere won't let a script set transition parameters, so the accents land on the plugin's defaults and presets writes your saved values into the project file (backing it up first). Premiere must be closed for that — it holds the project in memory — which is why the panel closes it for you.
    Reference

    Files & commands cheat-sheet

    Everything the pipeline reads and writes, in order.

    Quick run sheet — new video, start to finish

    1. New folder → copy pipeline.py into it → create an empty Scene folder.
    2. App Step 1: title + key points → copy prompt → AI → save as voice-over-script.txt.
    3. App Step 2: paste the script → copy prompt → AI → save all output as original-scenes-prompts.txt.
    4. Run py pipeline.py prompts → must print Verified.
    5. Flow AI: character reference + bulk extension with flow-ai-scene-prompts.txt → download all images into Scene, then keep only one image per scene.
    6. Record the voice-over reading voice-over-script.txt.
    7. Cutback → save as Transcript.srt.
    8. Run py pipeline.py build --scale 72 → renames the images, then check the console for LOW CONFIDENCE.
    9. Premiere → open YT Vid.prproj → File → Import → timeline.xml → open the sequence.
    10. Window → Extensions → Pipeline Transitions → Apply transitions (applies, saves, closes Premiere).
    11. Run py pipeline.py presets --open. 🎉
    voice-over-script.txtYour script, one breath per line. You read this when recording. Every two consecutive lines become one image scene — or every line, if Step 2 is set to 1 line per image. (Step 1)
    original-scenes-prompts.txtSCENE N + exact sentence + image prompt. Single source of truth for images, renaming and matching. (Step 2)
    flow-ai-scene-prompts.txtPrompts only, numbered 001:, 002: … and blank-line separated — feed to Flow. Auto-generated. (Step 3)
    Scene\The images. Downloaded raw (1.png, 1 (1).jpg…), renamed to "001 - sentence.jpg" by the build. (Steps 4, 7)
    Transcript.srtSubtitles of your recorded voice (Cutback). (Step 6)
    timeline.xmlThe finished Premiere sequence. Import via File → Import. (Step 7)
    apply-transitions.jsxAdds the Push / Zoom Blur accents after the import — they can't travel inside the XML, Premiere's exporter rewrites third-party transitions as a plain dissolve. Run by the Pipeline Transitions panel. Auto-generated. (Steps 7, 8)
    SFX\The sound library — default at D:\YouTube\Mr Wise Max\YouTube Video Template\SFX\, used by every video with nothing to pass. Drop files in loose and they're sorted by name into whoosh, impact, riser, ui, ambience; a subfolder overrides the name. A .wav holding several effects is split automatically. A local SFX\ inside one video beats the default. (Step 8 · one-time)
    SFX\credits.txtWhere every sound came from and under what licence. Auto-generated by sfx; --source "Epidemic Sound" stamps a whole bulk import at once. Files with no record are flagged UNKNOWN.
    pipeline.pyThe only script you copy into a new video's folder. prompts before Flow, build after recording, presets after Premiere; sfx to check the sound library. (Steps 3, 7, 8)
    <project>.prproj.bakAutomatic backup taken the first time presets edits your project. Delete it once you're happy. (Step 8)

    ✂️ Shorts Finder

    Drop in the video's Transcript.srt and it does the whole Shorts job. First it builds a prompt that hunts for the stretches standing on their own as a Short — Claude answers with line numbers, so what you see is the transcript word for word, with real timecodes to scrub to. Then click a candidate and it cuts that stretch into Flow-sized clips, measures each one's length off the timings, and builds the motion-graphics prompts. Both steps run in the Claude app, so neither costs API credits.
